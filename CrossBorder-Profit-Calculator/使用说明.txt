跨境电商利润计算器 V3.0——使用说明

一、如何打开
1. 打开这个文件夹。
2. 找到 index.html 文件。
3. 用鼠标双击 index.html，程序会自动在浏览器中打开。

二、如何使用
1. 按照输入框旁边的提示填写数据。可以选择自定义、Amazon、eBay、Shopify、TikTok Shop 或 AliExpress，系统会填入参考佣金比例；佣金仍然可以手动修改。
2. 点击“计算利润”。
3. 页面会显示销售收入、商品总成本、平台佣金、总费用、单件总成本、净利润、单件利润、利润率和成本占销售额比例。
4. 想重新填写时，点击“清空数据”。

三、盈亏平衡分析
1. 在主利润计算器填写成本、数量、佣金、汇率和当前售价。
2. 设置安全边际，默认是 10%，然后点击“计算盈亏平衡”。
3. 页面会显示单件综合成本、人民币和美元盈亏平衡售价、安全售价，以及当前售价的差距。
4. 可以点击采购、物流或广告费用上涨 10% 的模拟按钮；模拟不会修改原始输入。

四、商品报价助手
1. 点击首页“商品报价助手”卡片中的“开始报价”。
2. 填写单件采购成本、商品数量、各项总费用、平台、汇率和目标利润率。
3. 点击“生成报价”，查看最低售价、建议报价区间、预计利润和本地报价分析。
4. 点击“清空报价”可以重新填写。
如果佣金比例与目标利润率之和达到或超过 100%，系统会停止计算并给出提示。

五、多方案对比
1. 先在主利润计算器填写单件采购成本、数量、物流、其他费用、汇率和平台。
2. 点击“从当前数据填充”，可以把当前售价、广告费用和佣金复制到方案 A、B、C。
3. 分别修改三个方案，再设置利润率警戒值并点击“对比方案”。
4. 页面会显示三组利润指标和净利润柱状图，只提示盈利、亏损和低于警戒值，不判断最佳方案。

六、AI利润分析
完成利润计算后，点击“AI利润分析”，页面会根据当前结果给出盈利情况、利润率评价、成本结构、平台维度分析和 3 条优化建议。
该功能使用浏览器本地规则模拟分析，不调用外部 API。

七、导出PDF报告
1. 完成利润计算后，点击“导出PDF报告”。
2. 在浏览器打开的打印窗口中，选择“另存为 PDF”或“保存为 PDF”。
3. 确认保存位置后点击“保存”。
如果已经生成 AI 利润分析，AI 分析内容也会自动加入报告。整个过程只在本地浏览器中完成。
如果已经生成商品报价助手结果，报价结果也会自动加入报告。
如果已经生成多方案对比结果，对比表也会自动加入报告。
如果已经生成盈亏平衡分析，盈亏平衡售价、安全售价和当前售价差距也会自动加入报告。

八、公式说明
销售收入 = 商品售价（美元）× 美元兑人民币汇率（1 美元兑换的人民币金额）× 商品数量
商品总成本 = 单件采购成本 × 商品数量
平台佣金 = 销售收入 × 平台佣金比例
总费用 = 商品总成本 + 国际物流费用 + 平台佣金 + 广告费用 + 其他费用
净利润 = 销售收入 - 总费用
单件利润 = 净利润 ÷ 商品数量
利润率 = 净利润 ÷ 销售收入 × 100%
成本占销售额比例 = 总费用 ÷ 销售收入 × 100%
单件综合成本 = 单件采购成本 + 单件分摊物流 + 单件分摊广告 + 单件分摊其他费用
盈亏平衡人民币售价 = 单件综合成本 ÷（1 - 平台佣金比例）
安全售价 = 盈亏平衡售价 ×（1 + 安全边际）

注意：平台费率仅供估算，实际费率请以平台和商品类目为准。
这是一个离线网页工具，数据只在当前浏览器中计算，不会上传或保存。
